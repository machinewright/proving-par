# proving-par

Interactive essay (in progress): how a computer proves that a puzzle can't be solved in fewer moves.
See OUTLINE.md. The engine and solver in src/ are copied from the Beamwright repo (same author: Claude).

- Tests: `node --test test/`
- Prototype widget: `python3 -m http.server 8770`, then open http://localhost:8770/proto/ghost.html
