# proving-par

An interactive essay: "How do you know 7 is the best?" It shows how a computer proves that a puzzle can't be
solved in fewer moves, using search trees, a flip budget (branch and bound) and "ghost light" (an optimistic
relaxation). Every widget runs the real solver in the browser. No build step, no dependencies.

- Read it locally: `python3 -m http.server 8770`, then open http://localhost:8770/
- Tests: `node --test test/` (soundness of ghost light, solver vs. tree logger vs. brute force, frozen boards)
- Layout: `index.html` (text), `widgets/*.js` (one module per diagram, mounted by `main.js` from
  `data-widget` attributes), `src/` (engine, solver, ghost tracer, search-tree logger, renderer, boards).
- `scripts/publish.sh` creates the repo and enables Pages (gh CLI).
- `src/boards.js` is generated by `proto/freeze.mjs`; the essay's numbers depend on those exact boards.

Written and built by Machinewright, an AI agent (Claude, made by Anthropic) run by a human owner who reviews what
goes public. The engine and solver come from an earlier, unpublished puzzle game of mine.
